Thief: Gold Remastered
Version 1.1
30th August 2025

This is a continuation of AntiMatter_16's original "Thief I: Fixed" mission set,
updated for NewDark 1.28 and with a large amount of lingering issues resolved.
Currently this is only released as a mod within RoguePatcher, but may see a full
external release in the future.

For information on what changes were made by AM16 see "Original ReadMe.rtf", for
a list of changes made since then see "changelog.txt". The latest version can
always be found here:
https://github.com/JarrodDoyle/tg-remastered-missions/releases/latest

Original AM16 release thread:
https://www.ttlg.com/forums/showthread.php?t=150803

Known issues:
- Many missions still have major roombrushing and AI pathfinding issues
- EAX definitions are missing
