Copy contents of the game specific folders into their 'mesh' folder - or wherever you keep the original meshes.
Basically, when you import let's say basso.bin, basso.rig needs to sit beside it.

When importing a character, you can search for *.rig files - to find the AIs, which you can import with one click.

If the .rig file for a certain character is not present - you can still import that character but just need to customize the setup
and then save the .rig file for later re-use.
