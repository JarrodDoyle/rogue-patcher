Motion Database Tools credits
-----------------------------

Makmdb.ex was written by Shadowspawn (Randy Sybel). The Motion Schema files (.mos and .moc files) have been originally generated by Shadowspawn as well, using his tools.

They are available for download at: http://www.angelfire.com/games4/shadowspawn/Tools.html

Motion Database Editor and Motion Schemas are distributed with Dark Animation Tools with a permission of the author, and are added for convenience only. Dark Animation Tools use them to browse motions by schema and provide a GUI layer to edit them and re-build motion database with custom motions.
